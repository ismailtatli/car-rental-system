# Car Rental System

This project is a simple Car Rental System developed for the Object Oriented Programming course.

## Features
- Object Oriented Programming principles
- Car rental and return operations
- Payment management
- Unit testing with JUnit
- UML Class and Use Case diagrams

## Project Structure
- src/main/java : Source code
- src/test/java : Unit tests
- docs/uml : UML diagrams

## How to Run
Run the Main class using IntelliJ IDEA.

## How to Run Tests
Tests can be run using JUnit from IntelliJ IDEA.

## UML Diagrams
UML diagrams are located under the docs/uml directory.
